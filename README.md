Fix [MC-309606](https://bugs.mojang.com/browse/MC/issues/MC-309606)
> Multiple totems of undying can be used in the same damage tick, even though it should be impossible to die in the same damage tick a totem is used. The amount is unlimited and can be in the same game tick. This can be exploited in contraptions like “railguns”, which can kill any player in a single game tick.

## How does it work ?
It uses [Mixin](https://fabricmc.net/wiki/tutorial:mixin_introduction) to replace parts of the Minecraft code with a modified version of it.

## Compatibility
Totem fix should work with any mod. If you encounter any incompability, feel free to contact me and inform me of it.
